# 同行成林品牌準則

## 品牌核心

**正式名稱：同行成林**

**產品說明：群體真實行動與可驗證影響平台**

**品牌句：讓每一次真實行動，長成我們共同留下的森林。**

同行成林不是叫使用者每天打卡的獎勵程式，也不是只服務單一家庭的長者程式。它讓家庭、朋友、社區、學校、公司與志工團體組成樹伴圈，透過可見證的共行旅程，留下共同記憶與可追溯的社會及環境成果。

## 命名架構

| 層級 | 正式名稱 | 用法 |
| --- | --- | --- |
| 產品、App、公開網站 | 同行成林 | 所有使用者可見的主品牌 |
| 研究與專題全名 | 同行成林：群體真實行動與可驗證影響系統 | 研究所、競賽、技術報告與口試 |
| 群體 | 樹伴圈 | 家庭、朋友、社區、公司等共同參與單位 |
| 核心活動 | 共行旅程 | 包含接力、蒐集、城市探索等玩法 |
| 驗證能力 | 行動見證 | 依回饋價值配置自我確認、計時、位置、照片、短效碼或合作單位確認 |
| 數位成果 | 樹伴生命樹、年輪進度 | 呈現真實足跡與群體歷程 |
| 實體裝置 | 桌上生命樹、同行徽章 | 不使用英文產品名或型號當作對外名稱 |
| 合作端 | 共創夥伴台 | 旅程設定、短效動態碼、核銷與成效資料 |
| 全體成果 | 世界共生林 | 只呈現已獲資源、已執行且可追溯的成果 |

既有套件名稱、資料表、程式類別與裝置通訊欄位可保留英文，避免不必要的相容性風險；只要出現在使用者、合作單位、評審或公開網站面前，就必須優先使用中文共同語言。

## 品牌個性

- **溫暖但不幼稚**：重視陪伴與群體情感，不使用哄小孩的語氣。
- **有生命力但不浮誇**：用成長、季節、年輪與足跡說故事，不虛構影響數字。
- **簡單但不空洞**：每個畫面只要求一個主要動作，同時讓使用者知道為何而做、和誰一起做。
- **可信但不冰冷**：驗證、隱私與合作界線說清楚，仍以人與人的連結為主角。

## 文字規則

優先使用：「一起完成」、「輪到我接住這一棒」、「還差一個篇章」、「留下真實足跡」、「長成共同的年輪」。

避免使用：「賺幣」、「強制打卡」、「免費換一棵樹」、「保證改善健康」、「碳權」、「監控長輩」、「玩家黏著」。

對長者不使用命令或羞辱式連續紀錄；中斷旅程時提供延後、轉棒與替代行動。對商家不說單純買曝光，而說可衡量且自願參與的共行旅程。對政府不把活動數等同健康成果，清楚區分參與、持續、完成與後續研究。

## 視覺方向

- 主色：深林綠 `#176B4A`，代表信任、生命與長期累積。
- 輔色：新芽綠 `#B9DB68`，只用於進度、解鎖與關鍵提示。
- 溫度色：暖陽黃 `#F4C95D`，用於相聚、鼓勵與季節收藏。
- 警示色：珊瑚紅 `#EF755F`，只用於需要注意且可恢復的狀態。
- 背景：霧白 `#F5F7F5` 與暖紙白 `#FFFDF7`，避免大面積刺眼純白。

介面以清楚層級、大觸控區、可讀字級、足夠對比與單一主要行動為原則。裝飾必須服務「共同前進」與「生命樹成長」，不得用大量粒子、閃爍或複雜手勢妨礙高齡使用者。

## 名稱狀態

「同行成林」是目前正式工作名稱。二〇二六年八月二十二日的公開網路初步檢查未發現明顯同名 App 或平台，但這不等於商標法律意見；正式商用、成立公司或申請商標前，仍須由智慧財產權專業人員或官方系統完成類別檢索。
