# 據點到場見證與自願回饋核銷

狀態：開發中；未完成實機或場域驗收。這是共創夥伴台到可試辦流程的下一段，不代表合作已成立。

## 使用流程

1. 夥伴在提案中選擇是否需要現場到場碼；此條件隨安全與無障礙資訊一同送平台審核。一般免費旅程不受影響。
2. 已核准且在有效期間內的據點，由該組織管理員產生有效六十秒的到場碼。用一般手機、平板或電腦顯示，不先要求專用硬體。
3. 成員先依既有定位流程接取旅程；滿足計時等條件後，掃描現場碼並提交最新位置。伺服器同時核對組織旅程、短效碼、有效時間、定位精度與距離。
4. 到場見證、旅程完成與生命樹成長在同一交易中成立。同一帳號對同一合作旅程只記一次，切換樹伴圈不能再次領取；同一現場碼可以供多位不同成員使用。
5. 有自願回饋的旅程，完成者可另外產生五分鐘有效的領取碼，交由該組織管理員核銷。領取不是完成旅程或獲得年輪進度的必要條件。
6. 核銷由伺服器一次性更新，重送回報原領取時間並標示「先前已領取」，不能再次顯示為新成功；重新產碼使前一張領取碼失效。現場仍須依狀態交付回饋，系統不能保證人員不會重複交付實物。

## 見證及隱私規則

- 到場碼與領取碼使用不同格式的高熵隨機值，資料庫只保存雜湊；不放入網址、日誌或公開成效資料。
- 定位資料須為最近三十秒內（最多容許五秒未來時間），精度不超過五十公尺且在審核半徑內。只用於本次比對，不儲存原始座標或軌跡。
- 起訖時間與碼的過期時間均以伺服器為準；結束時刻起即不可首次完成或核銷。過期、錯旅程、未核准、跨組織、離線皆不能假報成功。
- 現場碼至少間隔十秒才能再產生；領取碼至少間隔十秒才能重發，避免重複點擊與無限制快速產碼。
- 樹伴圈移除後保留帳號層級的見證與領取狀態，只清空圈子關聯，避免刪圈重建後重領。帳號或活動刪除仍沿用資料庫刪除關聯；本版不是永久金融帳本。
- 只輸出去識別化的總數；一般定位抵達、複合到場見證、完成與核銷分開計算。不把掃碼等同購買、共同在場、正式志工時數、健康成果或植樹履約。
- GPS 可被偽造，短效碼也可能即時轉傳；本版只適合小額非現金試辦回饋，不宣稱百分之百防作弊。高價回饋仍需人工核對、預算及風險控管。

## 驗收要求

沿用現有服務公開介面與資料庫整合驗證：合法流程、多人成員使用同碼、過期碼、不同旅程、跨組織權限、無效定位、計時不足、切圈重領、同帳號並發完成、並發核銷、領取碼重發與重試。另驗證 API 資料格式與手機／夥伴台的過期、失敗、離線、操作中狀態。

畫面用共用介面工藝庫檢查：主要操作清楚、繁體中文、大字與窄螢幕可用、鏡頭權限失敗有說明、碼過期立即隱藏、敏感碼不在常駐列表顯示。正式完成須附操作畫面與實機掃碼證據；程式測試不能替代這一項。
