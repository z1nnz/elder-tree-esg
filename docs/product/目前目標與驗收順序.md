# 樹伴：目前目標與驗收順序

依使用者 2026-09-14 最新指示，本文件取代舊計畫的近期工作排序。當前優先級是外觀與可操作展示，不是擴充功能。舊計畫保留作背景，不代表現在要並行執行。

## 1. 完成主樹美術

骨架已重做；現在集中處理樹冠明暗、葉叢聚合與樹皮質感。

驗收須同時檢視整體輪廓、近看細節及旋轉側面；不能只挑一個好看的角度。保留正面、兩側及近景實際渲染證據，清楚標示尚未改善之處。以使用者提供的世界樹參考圖為視覺方向，不以模型數量、面數或測試通過替代美術品質。

## 2. 重整島嶼、瀑布與雲海

改善島壁像深色切塊、瀑布像白色線條、雲朵零散的現況。整合岩壁層次、水流厚度、落水霧氣與遠近景，形成完整場景。維持一座主島，不擴充群島、小鎮或人物系統。

驗收看完整構圖及連續動態，也看不同角度的遮擋、接縫與層次，不能只驗收局部材質。

## 3. 交付可操作展示

交付新版實際畫面與可開啟的展示，確認旋轉、縮放、返回正常。桌面拖曳尚未完成手動驗收，必須補上；程式存在、編譯成功或直接呼叫 SetView 不能替代實際輸入驗收。

明確記錄版本、建置產物、測試平台與操作結果。自動操作工具未成功送入位移時，不能宣稱拖曳正常，也不能直接判定產品壞掉。

## 4. 外觀定下來，再回到 App

先統一六階段樹木美術，再整理入口與導航，逐項驗收拍照辨識、定位、群體連動等功能。每一項都需要可觀察的完整流程，不把「有程式」當作「已完成」。
