# 樹伴圈共行旅程第一階段

## 目標

讓三至五名樹伴成員共同完成一段接力旅程，並在 App 中清楚看到誰完成哪個旅程篇章、還缺什麼，以及樹伴圈共同解鎖的生命樹成果。

第一階段驗證的是多人玩法，不宣稱已完成完整行動見證、商家自助上架或真實植樹營運。

## 第一條垂直切片

「讓春天回到生命樹」包含三個依序開放的旅程篇章：

1. 找到一束陽光。
2. 完成三分鐘舒展。
3. 找到一株新芽。

規則：

- 至少三名不同樹伴成員參與。
- 每名成員在本次共行旅程最多完成一個篇章。
- 已完成的篇章不可被重複計算。
- 三個篇章與三名不同成員都成立後，樹伴生命樹解鎖「春日紀念枝」。
- 第一版使用第一級自我確認見證，只提供一般年輪進度；不得用於優惠核銷、公益服務時數或真實植樹成果認定。

## 驗收條件

- 使用者可從地圖功能選單進入「樹伴圈」。
- App 顯示目前樹伴圈、成員數、共行旅程進度與每個篇章的貢獻者。
- 樹伴成員可以查看正在進行的共行旅程並完成輪到的篇章。
- 同一成員無法包辦所有篇章，同一篇章無法重複完成。
- 最後一個有效貢獻完成時，只增加一次樹伴生命樹成長值。
- 沒有連線時可瀏覽離線示範，但不得假裝建立真實足跡或增加年輪進度，且畫面必須明確標示示範狀態。

## 下一階段

1. 照片與人工覆核。
2. 計時、位置、停留與步數的複合行動見證。
3. 蒐集旅程、轉棒與逾時釋出。
4. 旅程據點短效碼與優惠核銷。
5. 年輪進度和成樹準備的雙軌台帳。
