# 溪岸與河床迭代

延續單島世界樹，先精修生命樹與浮島，再串入 App；不新增人物或硬體工作。

## 本輪資產

- 水路從急折的折線改為連續曲線，避免寬河床與溪岸在轉折處折疊。
- 新增兩片水下河床、四片溪岸，母稿可獨立編輯；河床位於水面下 0.035 場景單位。
- 溪岸寬度沿路略有變化，以頂點混合權重銜接濕土與草地；重用既有岩石、草地貼圖，沒有新增大型貼圖。
- 材質權重僅用於新溪岸材質，原主島與裝飾石的混合開關保持關閉。
- 主島生命樹資產合計 61,380 三角面、95 個網格物件。這不是整個 App 的渲染成本或手機效能驗收。

## 驗證內容

Blender 母稿重新載入後，四项檢查通過：595 個溪流頂點、三角面內部取樣、瀑布入口接縫，以及河床高度、面朝向、溪岸混合權重。另有故意破壞溪流頂點及瀑布接縫的反例檢查。

最大離地間距約 0.362412 場景單位，位於跨階梯過渡；不是流體模擬。Unity 新增匯入檢查，確保四片溪岸與兩片河床存在，且 FBX 保留混合權重。

頂點顏色的表面著色器輸入參照 [Unity 表面著色器說明](https://docs.unity.cn/Manual/SL-SurfaceShaders.html)。

## 目前的美術判斷

已改善水面直接貼在草地上的問題，但岸線仍偏人工渠道，溪流起點還缺自然泉源，階梯地形過於規整。旋轉檢查另發現瀑布從側面仍呈薄片，部分水流被溪岸遮住；下一輪需修改瀑布横截面與側向可讀性，不能只調顏色。未宣稱已達世界樹參考圖品質。

Unity 因磁碟不足無法建立日誌。檢查確認主工作區 `apps/mobile/build/app/intermediates` 為 Git 忽略的 Android 產物，無 Android 建置程序正在使用後，只移除該目錄約 1.9 GB。

保留原始碼、約 213 MB 的 APK、其他建置輸出與網頁展示成品。中間檔已刪除，不能直接還原，但可重新建置生成；可用空間由約 126 MB 回升至約 2 GB。未刪除其他重要專題。
