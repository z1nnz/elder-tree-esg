# 0007：三維雲境與隔離的本機建設試玩

- 狀態：採用
- 日期：2026-09-09

## 使用者要求

單座世界樹主島；背景也要三維建模；背景、新的島嶼建設與新玩法可一起製作。人物仍在後續階段，不擴張為完整戰鬥遊戲。

## 決策

使用 Blender 保存可編輯雲團母稿，匯出具實際厚度的雲網格，與主島一起在 Unity 渲染。天空色彩可以由天空材質處理，但不以背景插畫冒充立體雲海。替代 0006 的二維背景提案。

先實作島上三個建設位置、安放／收回晨光花圃及本機保存。此處是布置狀態，不是已驗證的行動成果；不寫入年輪進度、不授予紀念成果、不扣用戶資產，不取代 API 的權威狀態。

獨立美術試玩場景可明確顯示成熟樹。此選項只在本機試玩場景啟用；正式庭園仍使用既有資料橋接與狀態驗證，不把展示狀態傳回後端。

## 後續整合門檻

進入正式 App 前，須引入有所有權的布置資料、可用建設物清單、多人修改衝突處理、離線重送與伺服器驗證。正式解鎖來源必須連結真實足跡，不能用本機保存紀錄替代。長者仍可直接參與共行旅程，不被迫額外操作島上遊戲。

0005 的 Flutter／Unity 全螢幕邊界仍保留；本輪 Mac 試玩不能當作 Android、iOS 或瀏覽器整合通過的證據。
