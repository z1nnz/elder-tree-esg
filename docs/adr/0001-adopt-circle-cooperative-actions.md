# 以樹伴圈共行旅程取代家庭單次任務作為產品核心

產品以「樹伴圈」作為群體上位模型，家庭保留為第一個特殊類型；核心玩法改為由多名樹伴成員共同完成、具分級行動見證的「共行旅程」，而不是個人完成單次任務後取得代幣。這項選擇保留高齡家庭的首發場景，同時允許朋友、社區、公司、學校與政府活動使用同一套產品，並將年輪進度和成樹準備分成兩條不可混算的進度。

## 後續影響

- 既有家庭資料先遷移成家庭樹伴圈，不直接破壞家庭訊息、長輩模式與陪伴權限。
- 第一條接力旅程已支援認領、轉棒、30 分鐘逾時釋出及無障礙替代方案，並驗證依序接棒、不同成員與不重複成長；後續旅程仍須依行動價值逐步接上更強的行動見證。
- 真實足跡只能證明參與事實；真實植樹必須另外確認資金、種植名額、執行與維護責任。
