# 以接力認領成功時間作為完整計時見證的開始

## 背景

接力旅程原本只有第一級自我確認。第二篇章「喚醒水流」要求三分鐘舒展或慢呼吸，如果仍由使用者直接按完成，畫面敘述與實際見證強度不一致；如果另開一個本機倒數，離開 App、換裝置或修改手機時間又會失去可追溯性。

## 決定

- 計時篇章在伺服器確認認領時開始，沿用接力棒的 `claimedAt`，不另建立一個可能與認領狀態競爭的開始指令。
- App 只依伺服器回傳的開始時間與最低秒數顯示倒數；未到時按鈕不可完成，伺服器仍是最終判定者。
- 轉棒會以新接棒者的認領時間重新開始；逾時釋出會清掉舊認領，因此舊計時不能帶給下一人。
- 通過後以第二級「完整計時」保存開始時間、最低秒數、實際經過秒數與完成時間；重送沿用既有篇章與請求冪等規則。
- 一般行動與無障礙替代行動分別帶自己的見證模式和秒數，不能因改選替代方案而降低見證強度。

## 不代表什麼

完整計時只能證明從認領到送出至少經過指定時間，不能證明姿勢正確、持續動作、所在地點、同場、健康效果或公益服務。因此它只能累積一般年輪進度，不可直接用於優惠核銷、志工時數、成樹準備或真實生命樹成果認定。

## 後續影響

- 高價值回饋仍須使用位置、停留、步數、照片、短效碼或合作單位確認等複合見證。
- 若未來計時流程需要暫停、分段或引導動作，應新增獨立見證紀錄，不得把本次單段計時偷偷延伸成更強的證明。
