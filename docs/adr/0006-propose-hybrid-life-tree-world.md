# 0006：提案採用三維主樹與二維遠景混合的生命樹世界

- 狀態：提案中
- 日期：2026-09-01
- 關聯議題：[#53](https://github.com/z1nnz/elder-tree-esg/issues/53)

## 情境

全場景程序化低面數建模已證明資料節點、相機、行動結果與行動裝置程式庫可以整合，但人工檢視不通過正式美術門檻：主樹缺少三級枝梢與樹皮材質，雲和瀑布像白模；繼續增加同類幾何只會提高繪製成本，不能得到目標設計稿的遠景規模與厚塗質感。

樹伴真正需要即時改變的是主樹、中央島、十二個紀念掛點、成長階段與少量氣氛效果。遠方天空、雲海與旅程島在第一輪沒有操作與資料狀態，不需要承擔完整三維成本。

## 決策提案

1. 生命樹、盤根、中央島、紀念枝與近景瀑布維持 Unity 三維即時資產。
2. 遠方天空、雲海與兩座旅程島使用樹伴原創 3:4 二維背景板；不得使用外部參考圖或來源不明素材。
3. Unity 在三維主體上增加低頻枝葉風動、瀑布流動、少量水霧、色彩分級與有限環繞；降低動態時停止所有非必要運動。
4. Flutter／原生層繼續負責繁體中文、大字、讀屏、返回與操作，不把文字烘焙進背景。
5. 證據必須分開標示概念圖、二維背景板、Blender 預覽、Unity 編輯器畫面與實機畫面，不能互相冒充。

## 影響

優點是能在手機預算內取得穩定遠景品質，把主要建模時間集中在真正會成長和承載回憶的主樹；背景也可獨立壓縮與退化。代價是相機只能有限環繞，遠島不能提供大幅視差，背景光向改變時必須同步更新三維主光。

本提案在主要負責人確認混合場景方向、主樹正式模型與實機畫面以前不得改為「已採用」，目前白模與概念圖都不視為最終交付。
