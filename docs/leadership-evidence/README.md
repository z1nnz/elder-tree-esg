# 主要負責人證據索引

這個目錄把同行成林從想法到正式版本的責任鏈整理成可核驗資料，供專題審查、研究所申請與後續團隊交接使用。它不是宣傳頁，也不以大量提交數取代真實責任。

## 證據層級

| 層級 | 可接受資料 | 能證明什麼 |
| --- | --- | --- |
| 方向 | 產品需求、議題、決策紀錄、會議結論 | 誰定義問題與取捨 |
| 執行 | 分支、提交、合併請求、程式差異、電路與設計檔 | 誰實作或整合了什麼 |
| 驗收 | 測試輸出、檢查結果、裝置影片、畫面、缺陷紀錄 | 是否真的能運作 |
| 發布 | 標記、版本說明、建置雜湊、安裝檔產生方式 | 哪一版可被重現 |
| 試辦 | 同意程序、去識別化訪談、事件與修正紀錄 | 是否接觸真實使用情境 |

## 每筆紀錄規則

1. 使用日期、目標、角色、成果、驗證方式與公開連結。
2. 角色只能選擇：主要負責人開發與整合、主要負責人決策與驗收、其他組員貢獻、外部合作單位提供。
3. 無法公開的原始訪談或個資只記錄保存位置與去識別化摘要，不提交到公開倉庫。
4. 由 [`contribution-ledger.md`](contribution-ledger.md) 作為入口，不散落成無法查證的截圖堆。

## 研究所作品集建議呈現

作品集應選三至五個最能代表主要負責人能力的縱向案例，每個案例用「問題、選擇、實作、驗證、結果、限制」六段呈現。推薦優先使用：

- 家庭單次任務轉向樹伴圈共行旅程的產品與領域模型決策；
- 接力旅程在多人並行、冪等與逾期狀態下的資料一致性；
- 行動見證依回饋價值分級的安全與隱私設計；
- App、共創夥伴台與桌上生命樹的跨端整合；
- 真實試辦如何改變第二版設計。
