# 遠近景層次

本輪遵循程式修改準則技能，限定於外觀展示的距離霧與遠海混色，不改樹葉或 App。

- 外觀場景改為線性霧，32 公尺開始、135 公尺結束，使用偏藍天空色；主島主要落在清晰區域。
- 遠海材質原本不受場景霧影響，獨立將海天混色範圍從 70–150 改成 45–135 公尺。
- 保存正面、兩側、近景、橫幅與 72 幀連續實景於 `screenshots/world-tree-aerial-depth-2026-09-15/`。
- 原始 Unity 測試結果保存於同目錄 `遠近景測試.xml`；測試只能檢查既有行為，不代表美術驗收。

實景正面與右側均保持主樹和島壁清晰，遠雲對比降低、海天過渡提前。雲海仍有分組感，瀑布仍有帶狀輪廓；這不是參考圖品質的完成版。既有桌面候選展示尚未包含本輪修改，手機未更新。
