# 雲層與岩壁遮擋修正

## 重現與原因

新增 `OpaqueSurfaceInsideVolumeStopsCloudBehindIt` 實際渲染測試：同一個雲盒，將不透明黑色表面放在雲盒前端內側，再移到雲盒後方比較。修改前，前端被遮擋像素仍達 0.6301 亮度，未低於 0.1575 門檻；測試退出碼 2。

檢查順序為：體積積分未截斷、相機未提供深度、雲盒自身深度測試。確認原程式只計算光線與雲盒交點，沒有按不透明表面深度截斷；主相機也未啟用深度貼圖。

## 修改

主相機啟用深度貼圖。體積雲讀取場景線性深度，換算成該物件局部光線距離，將步進終點限制在可見不透明表面之前。保留既有薄底霧與四組雲峰候選配置。

- 修改前失敗 XML：`遮擋修正前.xml`。
- 修改後 39/39 測試通過：`遮擋修正後.xml`。
