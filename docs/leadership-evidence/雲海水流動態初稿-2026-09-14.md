# 雲海與水流動態初稿

本輪依最新指示暫停樹葉精修，先處理動畫、水流與雲海。此為候選場景，未宣稱達到參考圖品質。

## 本輪實作

- 加入六組相互重疊的島下雲層，使用世界座標，旋轉時保有遮擋與視差。
- 雲體內部密度隨時間緩慢流動，遵循既有減少動態設定。
- 瀑布流紋加寬並打散平行條紋；增加末端水霧的範圍、壽命與擴散。
- 保留單島和既有樹木，不投入角色、小鎮或 App 功能。

## 可核對證據

- Unity 批次 Capture 正常結束；輸出正面、左右 35 度、近景、橫幅。
- 72 幀連續實際渲染，12 幀／秒，約六秒；不是概念圖或生成影片。
- 本輪 Unity EditMode 測試 37／37 通過，原始結果 `/tmp/cloud-motion-tests.xml`。測試通過不等於美術驗收。
- 圖片與動畫目錄：`screenshots/world-tree-cloud-motion-2026-09-14/`。

## 實景審查與未完成事項

正面雲層已能銜接瀑布下方，但側視雲層仍有長條、分離的形狀；瀑布仍像平面水帶，河道與落差轉折仍生硬。下一輪應改善瀑布體積與轉折、水霧過渡及側面雲層銜接，不回到樹葉堆細節。雲海效能尚未在手機上量測。

本輪僅更新場景與渲染證據，尚未重建桌面或手機成品；既有展示 App 仍是舊版本。桌面手動拖曳未補驗，不能聲稱已完成。

## 第二輪：水幕弧度

在既有水幕网格上加入沿法線的橫向拱起與動態摺面，位移使用世界尺度；河道與瀑布上緣保持不動。加入側視亮度變化，降低白紋對比。重新輸出本目錄的 72 幀與各角度圖片，並重新組合動態 GIF。此目錄現代表第二輪候選版。

第二輪測試結果 `/tmp/water-volume-tests.xml`：37／37 通過。實際側視仍能看到窄薄水帶和生硬的落差轉折，因此此調整只能算局部改善，不能當作「水流厚度已驗收」。下一步需要修改瀑布出水口與橫截面幾何，並保留河道接地及接縫驗證。未重新建置展示 App。

## 第三輪：Blender 出水口幾何

新資產匯入後 Unity 測試 37／37 通過，結果保存於同目錄 `水流幾何測試.xml`。程式修改準則技能用於限定瀑布改動與保留接縫驗證；測試結果不替代視覺驗收。

使用 `refine_saved_waterfalls.py` 只調整母稿中的兩組瀑布及兩組泡沫網格，不重建樹葉。保留前六排接地頂點，後段改成逐漸轉向下墜的曲線與弧形橫截面。已輸出母稿、FBX、GLB；三角面仍為 218,316，沒有用增加葉片或模型數量替代本輪工作。

Blender 幾何檢查 7／7 通過，包含新增的漸進下墜與橫截面檢查；595 個溪流頂點仍貼地，最大端點接縫為 0.000000533 公尺。第一次 Unity 捕圖因套件管理器連線失敗而退出，確認程序終止後重試成功。此目錄的三角度與 72 幀已更新至第三輪；側視出水口較圓順，但水帶感與雲層長條外形仍未解決，不能宣稱視覺定稿。桌面與手機展示 App 均未重建。
