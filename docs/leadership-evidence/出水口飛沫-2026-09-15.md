# 出水口飛沫

本轮依程式修改準則技能限定修改於水流動態：在兩處瀑布出水口加入獨立向下飛沫，與末端緩慢擴散的水霧分開。飛沫使用重力、拉長粒子及固定隨機種子；上限每處 64 顆，並接入既有減少動態控制。

Unity 已重新生成場景，輸出正面、兩側、近景與 72 幀動態，資料位於 `screenshots/world-tree-water-spray-2026-09-15/`。38／38 測試通過，新增斷言實際模擬飛沫粒子確認世界座標速度向下，減少動態會清除兩組飛沫。測試原件為該目錄的 `飛沫動態測試.xml`。

實景飛沫仍偏細微，水幕大輪廓仍有帶狀感，尚未達到參考圖品質；不可把粒子存在或測試通過當作完成。未重新建置桌面／手機展示，也未增加拖曳驗收結果。下一輪應檢查飛沫是否在正常手機視距可辨識，以及是否與水幕形成自然過渡。
