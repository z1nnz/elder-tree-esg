# 照片辨識故障邊界

## 問題與修正

辨識服務未配置供應商時回傳 `rules-only`／FAIL；API 原本接受為正式見證判定。現在拒絕此模式並回傳 503。網路失敗、逾時、無效 JSON 或不符合資料契約的回覆同樣歸為服務不可用。真正供應商的 PASS／REVIEW／FAIL 不變。

此變更集中於 `PhotoVerifierService`，未擴充玩法。錯誤不回傳上游私有內容。

## 證據

- `npm run test -w @elder-tree/api -- src/evidence/photo-verifier.service.test.ts`：9 項通過（無外部請求）。
- `npm run typecheck -w @elder-tree/api`：成功。
- 讀取 `PersistentStoreService` 確認：直接拍照的辨識呼叫在判定寫入交易之前；儲存照片路徑捕捉服務例外時更新 EvidenceStatus.ERROR 並重新拋出，不建立正式辨識結果。未有 verification 的見證可再次嘗試處理。

以上是單元測試與程式流程核對；未執行真實資料庫整合測試，未測手機端重試操作，未呼叫真實 AI。服務尚未部署，完整實機見證流程仍未驗收。
