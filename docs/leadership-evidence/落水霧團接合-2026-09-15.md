# 落水霧團接合候選

優先順序仍依最新使用者指示：水流、動畫、雲海，暫停樹葉精修。

## 改動與原因

原本水霧位置使用瀑布包圍盒中央與最低高度，沒有沿著彎曲水幕定位。本輪改為取模型 UV 接近 (0.5, 0.88) 的頂點並轉成世界座標，讓水霧接在水幕消散區。加大粒子尺寸與向外擴散角度，降低上升速度，保留向下飛沫的獨立設定。

## 驗證

- 實景擷取完成：三個角度、近景、橫幅及 72 幀序列。
- 人工檢視序列第 0 與 71 幀：兩道水幕末端都有可見霧團，沒有完全遮住主樹。仍有柔糊、缺少翻捲紋理的問題，不列為最終美術通過。
- Unity EditMode 38/38 通過；增加兩道瀑布與末端水霧位置相符、減少動態清除水霧的斷言。
- 無損動態為 72 幀、6000 毫秒，首幀與來源像素一致。
- 尚未重建桌面展示、未驗收拖曳，也沒有更動 App。
