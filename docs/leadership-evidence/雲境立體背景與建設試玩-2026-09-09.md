# 雲境立體背景與建設試玩

## 本輪交付範圍

承接「背景跟新的島嶼建設還有新的玩法一起製作」，在同一座島上實作遠觀與近觀建設流程。正式名稱仍為「樹伴」，場景稱「雲境」、第一個建設物稱「晨光花圃」。

- Blender 可編輯雲海母稿，匯出九組有厚度的封閉網格，共 23,804 三角面。Unity 使用三維雲團、天空漸層材質；不是相機前的背景照片。
- 本機路徑：走進雲境 → 溪畔／樹蔭／望雲台 → 安放花圃或收回 → 返回原全景。
- 花圃狀態保存於本機偏好，不扣代幣、不給真實行動獎勵、不改伺服器資料。
- 進入前的旋轉、縮放及鏡頭位置會保存；返回不跳到 GPS 首頁。建設期間保留雲與水流動畫，暫停環繞鏡頭。減少動態時省略鏡頭過渡。
- 獨立 Mac 美術試玩場景明確啟用成樹展示；正式庭園場景不因此獲得未賺取的成長進度。

## 關鍵工程修正

FBX 具有單位轉換父節點。驗證雲團厚度與計算漂移時，必須使用轉換後的世界單位，不能拿局部網格尺寸或局部位移直接代表公尺。獨立程式測試曾發現雲團大幅移動遮住主樹，已針對 100 倍匯入比例加入回歸測試。瀑布頂點擺動也改在世界座標計算，避免 1.2 公分振幅變成大幅折線。

環境控制器補上執行時初始化，避免只在編輯器呼叫建置方法後才有動態。鏡頭暫停與整體環境停用分開，避免進入建設後瀑布與雲全部靜止。

## 成品位置與重現

原始模型：`art-source/blender/雲境立體雲海_母稿.blend`。

Unity 選單「樹伴／建置本機雲境試玩」輸出 `apps/life-tree-unity/Builds/雲境試玩.app`。該目錄已在 Unity 專案的忽略清單；原始碼與場景入版控，編譯產物不塞進 Git。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/blender/build_cloud_world.py
/Applications/Unity/Hub/Editor/6000.0.82f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath apps/life-tree-unity -executeMethod TreeCompanion.Editor.CloudGardenSceneBuilder.BuildMacPreview -quit -logFile /tmp/cloud-garden-build.log
open apps/life-tree-unity/Builds/雲境試玩.app --args -screen-width 480 -screen-height 800 -screen-fullscreen 0
```

試玩鍵盤：啟動後 Enter 進入；首次 Enter 安放，已安放時 Enter 收回；Escape 返回。位置按鈕共三個，正式手機觸控與讀屏仍待驗收。寬螢幕操作板限制為固定邏輯寬度，不再按整個螢幕寬度放大遮住半座島。

測試期間發現編輯器靜態捕捉沒有執行中的事件系統；焦點設定現在容許靜態渲染情境，而按鈕測試則放到真正執行模式，不以手動強制呼叫啟動生命週期掩蓋差異。

## 尚未完成

這是本機建設原型，不是整個 App 成品。尚未接入 Flutter 首頁、多人同步、共行解鎖、伺服器存檔或正式獎勵。沒有自由拖曳建造、人物移動、戰鬥或完整角色扮演玩法。

美術也未達世界樹參考圖的完成度：主島與樹的尺度仍偏盆景、雲邊緣仍有實心感、花圃使用簡單幾何造型，瀑布與水霧還需精修。截圖與測試證明本輪具體進度，不證明最終美術品質。下一輪應重構主島尺度、地面路徑與雲的輪廓層次，而非宣稱已具備大型遊戲製作品質。
