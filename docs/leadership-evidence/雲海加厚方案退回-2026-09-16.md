# 雲海加厚方案：未採用

本輪比較兩個實際渲染候選，沒有將它們建置進桌面展示。

候選設定：連續雲體高度由 5.6 增至 9.4，中心由 -6.1 降至 -6.8；底層高度場由 `-.30 + billows*.85` 改為 `-.48 + billows*.65`；以 13、29 倍三維噪聲侵蝕密度。第一版使用 28 次光線取樣，第二版僅雲海提高至 64 次。

## 實際結果

- 28 次版本通過 38 個自動測試，但實景兩側形成規則層狀條紋，像堆疊的板片，不是自然雲峰。
- 64 次版本的條紋仍存在，不能把問題歸結為取樣次數不足；提高取樣還增加運算成本。
- 因外觀不合格，已撤回本輪著色器、位置和高度改動，保留既有桌面展示。這輪不宣稱美術改善完成。

比較資料保留在 `screenshots/world-tree-cloud-relief-2026-09-16/` 與 `screenshots/world-tree-cloud-relief64-2026-09-16/`。第一版另有 6 秒動態；第二版保留原始序列。

下一步應檢查雲層密度輪廓和自遮蔽造成的規則層次，或改用有明確主次的非連續雲峰覆在薄底霧之上；不要再次直接拉高同一平滑雲毯。
