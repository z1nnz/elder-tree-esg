# 同行成林加速交付計畫

## 雙軌週期

對外研究與試辦週期維持十四至十六週，才能包含需求、開發、實地試辦、觀察、修正與成果整理；實際產品開發採高密度短衝，不把展示版拖到最後一週才出現。

| 實際節奏 | 可展示成果 | 對外研究週期中的位置 |
| --- | --- | --- |
| 第 1～3 天 | 品牌、共同語言、主要負責人證據鏈、完整核心流程與缺口清單 | 問題定義與研究設計 |
| 第 4～7 天 | 可操作的樹伴圈、接力旅程、行動見證與生命樹回饋 | 第一版原型 |
| 第 8～14 天 | 精緻 App 主流程、長者模式、錯誤與離線狀態、可重現展示資料 | 可用性修正 |
| 第 15～21 天 | 共創夥伴台、短效動態碼、成效摘要、桌上生命樹串接展示 | 系統整合 |
| 第 4～6 週 | 小規模場域試辦、訪談、事件處理與第二輪修正 | 實地試辦 |
| 第 7～16 週 | 持續率觀察、合作諮詢、限制分析、研究所作品集與技術報告 | 研究與成果整理 |

前二十一天的目標不是假裝完成所有商業合作，而是交付「可安裝、可操作、可驗證、可展示、可說清楚限制」的完整系統。合作簽約、正式植樹與長期健康效果只能在真實資源和資料成立後宣稱。

## 第一版必須形成的閉環

1. 使用者建立或加入樹伴圈。
2. 樹伴圈開始一段接力旅程。
3. 不同成員依序完成旅程篇章。
4. 系統依回饋價值要求不同強度的行動見證。
5. 真實足跡不可重複計算，最後一棒只發放一次共同成果。
6. 樹伴生命樹顯示共同年輪、紀念枝與成員貢獻。
7. 合作據點可產生短效動態碼並查看去識別化完成資料。
8. 桌上生命樹可顯示目前旅程、輪棒與完成回饋。

## 第一輪試辦邊界

- 三至五個樹伴圈，共十五至三十人。
- 優先一個桃園社區或高齡據點，加上一個志工協力窗口。
- 只試辦一段接力旅程、一段蒐集旅程與一段城市探索。
- 商家旅程必須自願參與，免費核心進度不得要求消費。
- 真實植樹先完成合作流程、成本、土地、樹種及維護責任諮詢，不先承諾每圈一棵。

## 完成定義

第一階段不是以畫面數量判定完成，而是同時達成：

- 新使用者能在無口頭指導下走完核心流程；
- 關鍵狀態在重新整理、重送與多人同時操作下仍保持一致；
- 手機、後端、合作端與桌上生命樹的資料語意一致；
- 所有宣稱可追溯到測試、畫面、裝置、訪談或正式合作資料；
- 主要負責人能用提交、決策、審查、測試與發布紀錄重現開發歷程。
